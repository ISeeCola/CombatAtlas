# 每日战斗设计资料巡检

香港时间每日 09:00 增量扫描。任务读取本地工作规范、priority sources、registry、双工作簿和历史，以 canonical URL、平台 ID、标准化标题及讲者/会议去重；每天最多把 3 条最高价值候选写入 review 表。

自动化最高只能推进至“待人工复核”，不得批准入库、修改主表、提交 Git、推送 GitHub 或发布网页。无变化保持安静；仅在新增候选、链接失效、来源修正、文件锁、失败或需要人工决定时通知。Excel 文件锁定时写入忽略的 `pending/`，下次先幂等重放。

遇到 GDC Vault 内容时，先寻找 GDC 官方 YouTube 或其他官方公开视频；视频可得时优先记录视频链接，Vault 作为关联证据。重新处理“已拒绝”条目前必须读取 review 表末列“评论”的修改意见，并更新原记录，不得新建重复候选绕过反馈。
